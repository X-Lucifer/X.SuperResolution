# X.SuperResolution Installer

This folder contains the NSIS installer script for packaging the published
`X.SuperResolution` desktop application into a Windows setup executable.

## Prerequisites

- .NET 8 SDK
- NSIS installed and `makensis.exe` available in `PATH`
- A Windows `win-x64` publish output

## Build Publish Output

Run from the repository root:

```powershell
dotnet publish X.SuperResolution\X.SuperResolution.csproj -c Release -r win-x64 --self-contained true
```

The installer script reads files from this default publish directory:

```text
X.SuperResolution\bin\Release\win-x64\publish
```

## Build Installer

Run from the repository root:

```powershell
makensis installer\X.SuperResolution.nsi
```

The NSIS script is saved as UTF-8 with BOM because it contains Simplified
Chinese language strings. Keep that encoding when editing the file.

The setup executable is generated under:

```text
artifacts\installer
```

The output file name includes the published executable version, for example:

```text
X.SuperResolution-Setup-1.0.9683.42291.exe
```

## Reinstall Behavior

If the application is already installed, the installer reads the current-user
uninstall registry entry and silently runs the existing uninstaller first.

After the uninstall registry entry is removed, the current setup process
continues with the normal installation pages. If the old version cannot be
removed, setup exits with an error message.

## Installer Language

The installer shows a language selection dialog when it starts.

Available languages:

- Simplified Chinese
- English

Simplified Chinese is the default because it is listed first in the NSIS script.

## Values Read Automatically

You normally do not need to edit generated values manually.

The script reads project metadata from:

```text
X.SuperResolution\X.SuperResolution.csproj
```

It reads:

- `Company`
- `Authors`
- `Copyright`
- `RepositoryUrl`

It reads version information from:

```text
X.SuperResolution\bin\Release\win-x64\publish\X.SuperResolution.exe
```

Generated NSIS metadata is written to:

```text
installer\Generated.AppInfo.nsh
```

Do not edit this file by hand. It is regenerated each time `makensis` runs.

## Wizard Image

The installer uses:

```text
installer\logo.jpg
```

as the wizard image source. NSIS requires BMP for wizard bitmap controls, so the
build automatically converts `logo.jpg` to:

```text
installer\Generated.WizardImage.bmp
```

Do not edit the generated BMP. Replace `logo.jpg` if you want to change the
wizard artwork.

## Common Customization

Default publish directory:

```nsis
!define DEFAULT_PUBLISH_DIR "..\X.SuperResolution\bin\Release\win-x64\publish"
```

Default install directory:

```nsis
InstallDir "$LOCALAPPDATA\Programs\${APP_NAME}"
```

The current script installs for the current user and does not require
administrator permission.

To install under `Program Files`, change:

```nsis
InstallDir "$PROGRAMFILES64\${APP_NAME}"
RequestExecutionLevel admin
```

## Generated Files

These files are generated during installer build and should not be committed:

- `installer\Generated.AppInfo.nsh`
- `installer\Generated.WizardImage.bmp`
- `artifacts\installer\*.exe`
